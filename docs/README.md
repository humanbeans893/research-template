# docs/ — 人間向けドキュメント置き場

このディレクトリは、**人間が読むための研究ドキュメント**を蓄積する場所です。
エージェント向けの運用ルール(`AGENTS.md`)とは役割を分離しています。

## ここに書くもの

- **研究ログ** — 何を試し、何が分かったかの記録
- **意思決定記録** — 手法・データ・設計の選択と、その理由
- **データの由来メモ** — 入手元、取得日、加工履歴、利用条件
- **打ち合わせメモ** — 議論の要点と決定事項

## ここに書かないもの

- パス・コマンド・環境構築などの**事実**は `README.md` / `AGENTS.md` へ
- コードで表現できることはコードとテストへ

目安: **「なぜそうしたか」は docs/、「どうやるか」は README/AGENTS.md**。

## 定型ドキュメント(セッション引き継ぎ系)

- `../STATE.md` — 運用状態の単一ページ。セッション開始時に最初に読む
- `../experiments/EXP_SUMMARY.md` — 実験の索引と状態(撤回を含む)。`STATE.md` の次に読む
- `../experiments/JOBS.md` — 長時間ジョブ台帳(投入直後に記録)
- `launch-checklist.md` — 高コスト実行の投入前チェックリスト
- `guardrails.md` — 撤回した主張と、繰り返し禁止の失敗パターン
- `ideas.md` — 仮説と却下済みの方向

## 使い方

1. `docs/templates/` の雛形をコピーして書き始める。
2. 推奨ファイル名:
   - 研究ログ: `log-YYYY-MM-DD-<topic>.md`(例: `log-2026-07-16-baseline-fit.md`)
   - 意思決定記録: `decision-NNN-<slug>.md`(例: `decision-001-use-xarray.md`)
3. サブディレクトリはファイルが増えてから切る(テンプレートは最小構成を保つ)。
