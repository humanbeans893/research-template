# 実験インデックス

**何を試して、何が残ったか。**新しいセッションは `STATE.md` の次にこれを読みます。

各実験の詳細は `NNN_<slug>/README.md` にあります。ここは一行で引くための索引で、
**特に「撤回」「訂正」を見出しから分かるようにする**のが目的です。本文で撤回した結論が、
見出しや一行の要約だけを読むと生きて見える事故は、実際に起きます。

運用ルール:

- 新しい実験を作ったら、この表に1行足す。`tests/test_repo_structure.py` が実験ディレクトリと
  表の対応を検査するので、忘れるとテストが落ちる。
- 結論が変わったら、同じ行の「一行で」と「状態」を直す。
- **撤回・訂正したら、状態欄に必ず書く**(日付、何を撤回したか、どの実験・記録が根拠か)。
  理由と証拠は `docs/guardrails.md` に同時に書く。
- 150行を目安に収める。行が長くなったら、詳細を各実験の README へ移して一行を短くする。
